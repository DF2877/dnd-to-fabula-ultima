# D&D to Fabula Ultima

A browser-based tool for converting Dungeons & Dragons 5e/2024 content into Fabula Ultima-compatible stat blocks and character sheets.

## Goals

This project aims to:

- Convert D&D monsters into Fabula Ultima adversaries
- Convert D&D player characters into Fabula Ultima characters
- Preserve the flavor and identity of the original creature or character
- Generate clean, printable Fabula Ultima style character sheets
- Export completed sheets as images or PDFs

## Status

This project is currently in early development. The sheet layout is functional, and species, affinity, and rule automation are actively being implemented.
